# DIA Business — V1
نسخه پایه حسابداری و مدیریت کسب‌وکار مهندسی برق.

## اجرا
فایل‌ها را روی GitHub Pages قرار دهید. برای PWA و Service Worker بهتر است برنامه با HTTPS اجرا شود؛ GitHub Pages این مورد را فراهم می‌کند.

## امکانات V1
- SPA با Vanilla JavaScript
- طراحی RTL و Mobile First
- IndexedDB
- PWA و کار آفلاین
- مشتریان
- محصولات
- خدمات
- پروژه‌ها
- فاکتور فروش
- چاپ فاکتور
- خروجی تصویر فاکتور
- حسابداری ساده درآمد/هزینه
- گزارش صورتحساب مشتری
- Backup / Restore JSON

## نکته
اطلاعات روی همان دستگاه ذخیره می‌شوند. قبل از حذف داده‌های مرورگر یا انتقال به دستگاه دیگر، از بخش تنظیمات بکاپ بگیرید.
